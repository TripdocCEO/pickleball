# 사진 교체 방법 — 파일만 넣으면 끝입니다

이 폴더에 **아래 이름 그대로** 사진을 저장하면 사이트에 즉시 반영됩니다.
코드는 손댈 필요 없습니다. 파일이 없으면 예시 이미지가 자동으로 대신 표시됩니다.

## ✅ 메인 사진 — 적용 완료

`hero.jpg` (704×1500, 150KB) 가 이미 들어가 있어 홈 첫 화면에 표시됩니다.
세로 사진이라 인물 상반신이 살도록 3:4 카드로 자동 조정됩니다.

다른 사진으로 바꾸시려면 이 폴더의 `hero.jpg` 를 덮어쓰고 브라우저에서
**Ctrl+F5**(강력 새로고침) 하시면 됩니다. 가로 사진을 넣으면 원본 비율 그대로
표시되므로 잘림 걱정 없이 넣으셔도 됩니다.

> ⚠️ 현재 이미지는 AI 생성본입니다. 오픈 전 실제 코트 촬영본으로 교체하세요.
> 실제와 다른 시설 이미지는 방문 후 실망으로 이어집니다.

## 전체 파일 목록

| 파일명 | 쓰이는 곳 | 권장 컷 |
|---|---|---|
| `hero.jpg`    | **홈 첫 화면 대표컷** | 인물 액션 또는 코트 전경 (세로·가로 모두 가능) |
| `group.jpg`   | 소셜매치 페이지, 홈 갤러리 | 여러 명이 함께 치는 장면 |
| `solo.jpg`    | 처음 오시는 분, 홈 갤러리 | 1인 리턴·서브 동작 |
| `wide.jpg`    | 유소년·대회, 홈 갤러리 | 코트 3면이 보이는 실내 전경 |
| `court.jpg`   | 부산 랜딩, 홈 갤러리 | 사람 없는 코트 라인 클로즈업 |
| `outdoor.jpg` | 기장 랜딩, 홈 갤러리 | 야외 코트 또는 단체 사진 |
| `gear.jpg`    | 홈 갤러리 | 대여 패들·공 진열컷 |

파일 형식은 `.jpg` 로 맞춰 주세요. (다른 이름·확장자는 인식하지 않습니다)

## 촬영 체크리스트 (기획서 §09)

- 코트 광각 · 경기 장면 · 라운지 · **주차 입구** · 강습 · 아이 수업 — 각 3컷 이상
- 긴 변 1600px 이상
- 관람석 사진 필수 — 유소년 신청 전환에 직결됩니다
- 주차 입구 사진이 방문 결정을 크게 바꿉니다

## 권장 사양

- JPG, 파일당 400KB 이하로 압축 (모바일 로딩 속도)
- 인물이 식별되는 사진은 촬영 동의를 받아 주세요
- AI 생성 이미지는 실제 시설 사진처럼 쓰지 마세요 — 오픈 전 실제 코트 촬영본으로 교체
